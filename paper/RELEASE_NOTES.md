# TriCasRank paper materials

Reproducibility materials for *A Three-View System for CRISPR-Cas12a crRNA
Activity Ranking*. The release adds manuscript-specific inputs, identity
partitions, fixed/nested predictions, original statistical analyses, controlled
perturbations, classic baselines, figure source data, S6 and an additional
all-development refit. The original default model and command line are retained.

Download `inputs`, `results` and `nested` to reconstruct the complete paper
analysis, or `candidate` for independent inference. Extract selected archives
into one directory and follow `paper/README.md` at the commit recorded in
`release_manifest.json`. Code is Apache-2.0; derived research artifacts follow
the documented CC BY 4.0 scope and upstream attributions.
