这里保存正式 `20% D + 47% B + 33% C` 工具的全部决策依据：8,417 行 cross-fitted 预测、2,217 行历史固定预测、复算指标、2,000 次配对 target-cluster bootstrap，以及 5,151 个粗网格、20,301 个总体细网格和 101,505 个分折细网格。
