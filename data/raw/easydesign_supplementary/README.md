# EasyDesign repository data files

These four workbooks are unmodified data files from the official [EasyDesign GitHub repository](https://github.com/scRNA-Compt/EasyDesign), not worksheets extracted from the publisher's combined Tables S1-S9 workbook.

They were verified byte-for-byte against upstream commit `5c06a30d0a43be28a958831587f6ab706c2d4876` on 2026-08-14. Their SHA-256 values are recorded in the root [third-party notice](../../../THIRD_PARTY_NOTICES.md) and in `data/metadata/sha256_manifest.tsv`.

`Table S2.xlsx` contains the repository exports named `Training data` (10,634 records), `Augment data` (31,993 records) and `Test data` (1,358 records). The final V2-2 feature table is an adaptation whose formal publisher-workbook lineage and transformations are described in [the data contract](../../../docs/DATA.md).
