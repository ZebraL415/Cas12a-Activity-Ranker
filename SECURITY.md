# Security and responsible disclosure

This repository is research software and is not intended for clinical decision-making or autonomous biological experimentation.

Please report the following privately through GitHub's private vulnerability-reporting feature, if enabled:

- arbitrary code execution or unsafe file handling;
- dependency vulnerabilities that affect the supported workflow;
- accidental inclusion of private sequences, credentials or personal information;
- model files or examples that do not match their documented checksums.

Do not include sensitive sequences or personal data in a public issue. General reproducibility bugs and documentation problems may be reported with the public bug-report template.

Only the latest default branch is supported. A response-time commitment has not yet been established for this academic project.
